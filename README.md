# 미니프로젝트: 쇼핑몰 장바구니 & 할인 쿠폰
- 진행일 : 2026-11-09 ~ 11-10 (1일간)
- 참여 인원: 1명 (박정은)
- 문의 담당자: 박정은 

##   프로젝트 개요 
- 쇼핑몰의 상단 메뉴를 보고 상품을 담기, 빼기 후 장바구니를 확인 할 수 있음
- 사용 가능한 쿠폰이 있는지 확인 가능
- 쿠폰이 있을 경우, 쿠폰을 사용할 수 있음 (단, 쿠폰은 1개만 사용 가능)
- 결제 후 영수증 출력 

## 주요 기능
- 1. 상품 목록 : 현재 쇼핑몰에 있는 상품을 볼 수 있습니다.
- 2. 담기 : 상품 목록에서 원하는 상품을 장바구니로 담습니다. 
- 3. 빼기 : 장바구니에 담긴 상품을 장바구니에서 뺍니다. 
- 4. 장바구니 : 상품 목록에서 담은 상품을 보여줍니다. 
- 5. 쿠폰 : 보유하고 있는 쿠폰을 보여줍니다. 
- 6. 결제 : 영수증 출력과 함께 결제됩니다. 

## 프로젝트 작업 현황 

|기능 | 상세 기능 | 구현 여부|
| --- | --- | ---|
| 1. 상품 목록 | 구매 가능한 상품 목록 | yes |
| 2. 담기 | 상품 담기 | yes |
| 2. 담기 | 품절 상품 | 진행 중(보완) |
| 2. 담기 | 재고 부족 | yes |
| 3. 빼기 | 상품 빼기 | no |
| 4. 장바구니 | 장바구니 목록 | no |
| 5. 쿠폰 | 사용 가능한 쿠폰 목록 | no |
| 6. 결제 | 결제 완료 | no |
| 7. 종료 | 쇼핑몰 종료 | yes | 


## 실행 방법 
* step 1. F5를 눌러 쇼핑몰은 엽니다. (중간에 닫고 싶을 땐 : shift+F5 또는 "q" 입력)
* setp 2. "1"을 입력하여, 상품 목록을 엽니다. 
* setp 3. 구매하고 싶은 상품의 번호를 "상품 번호:"에 입력합니다. 
* step 4. 구해하고 싶은 수량을 "수량: "에 입력합니다. 
* step 5. 지금까지 담긴 상품 목록을 보고 싶으면, "선택: "에 "4"를 입력합니다. (장바구니)
* setp 6. 빼고 싶은 상품이 있는 경우, "선택: "에 "3"을 입력 후 상품 번호를 입력하여 제외합니다. 
* step 7. 현재 보유 쿠폰 목록을 확인 후 사용 할 쿠폰을 적용합니다. (1회 결제당 쿠폰 1장 사용 가능, 중복 사용 불가)
* step 8. 상품을 결제합니다. 
* step 9. "q"를 입력하여, 쇼핑몰을 종료합니다.
